# Pizza-Sales-Analysis
Pizza sales analysis using SQL Server and Power BI

## Project Overview
An interactive pizza sales dashboard created using SQL Server and Power BI.

## Tools Used
- SQL Server / SSMS
- Power Query
- DAX
- Power BI

## Analysis
- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Sales by Pizza Category
- Sales by Pizza Size
- Top & Bottom Performing Pizzas
- Daily & Monthly Sales Trends
